# Fixed external-case use of the analysis record

This study is closed. Two fresh, author-operated AI contexts each analyzed four
fixed external decision units, producing eight records. The study ran no target
program, repair, benchmark worker or new native experiment. Its outcome is the
justification of proposed actions within supplied source packets.

Start with the [complete adjudication](ADJUDICATION_B.md), its
[read-only crosscheck](ADJUDICATION_A_REVIEW.md), and [closure](CLOSED.json).
All eight concrete recommendations meet the prewritten admissible-action
reference and its necessary premises. A/E1 omits one secondary same-version
contract phrase; that omission remains visible. Historical execution/authority
unknowns remain unknown, not known-correct bug labels. These are descriptive
project-side judgments, not population accuracy or benchmark scores.

Both were within the fixed 40-command/20-minute limits, each with one attempt.
All four initial project-history flags were false in both pre-content receipts.
The complete frozen input set remained unchanged. There were no missing records,

[Run audit](RUN_AUDIT.public.json) and `records/A/`, `records/B/` retain original
answers, context receipts, launch/parent-wait receipts, empty stderr and outward

remain available. No hidden reasoning or credentials are distributed.

Launch configuration disabled project-memory/doc injection, web search and
delegation; retained commands show only packet reads and own-output writes.
Filesystem boundaries relied on instructions and log review, not an OS sandbox.
Supplied-context receipts do not prove absence of public-case training exposure.
The default official ChatGPT backend's precise model/version is UNKNOWN; the
contexts are not two independent model families. The logs report token usage
but support no cost-saving comparison.

## Interpretation and reproduction scope

The endpoint is application of a fixed record to four purposively selected
units in two frameworks. E3/E4 share one source family, and E4 is documentation,
not an incident. There is no untreated comparison, human-use evaluation,
population accuracy estimate, demonstrated fix or effect on task performance.
The result cannot attribute fewer errors or effort savings to the worksheet.
The study stops after these eight records, regardless of manuscript reviews.

Readers can inspect the complete inputs, answers and prewritten alternatives
without executing anything. The archived launcher records the original procedure;
its installation-specific executable path is anonymized as `<codex-cli>` and
the original freeze paths as `<transfer-workspace>`/`<project-root>`. It is
not a drop-in rerun command. A new execution would need its own isolated packet,
CLI installation, login, context disclosures, budgets and seal; it would be a
new stochastic analysis, not reproduction of the same answers. No rerun is
needed to inspect the reported evidence.
