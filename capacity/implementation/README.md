# Inspection closure for the fixed installed policies

This directory contains the smallest selected code/configuration closure used here to explain the eight actual policies, plus their identity/export records. It is not a runnable host package. No copied experiment code was imported or executed while creating this supplement.

* `packages/L`, `packages/P`, `packages/Ln`, and `packages/Pn` contain their original code and package manifests. The parsing, admission, localization and selection differences are described in [METHODS.md](../METHODS.md).
* `analysis/raw_repo_capacity_comparison_v1` contains current routing, stage budget/permissions, source-domain checks, task selection, scheduling, constants and workflow rebinding.
* `analysis/raw_repo_localization_v1` and `analysis/raw_repo_localization_scored_v2` expose ordinary discovery/native behavior, P vote submission, and the N/L/P/LP host flow.
* `analysis/raw_repo_comparators_v1` exposes naive locator/editor integration and the complete-loop mini wrapper. `analysis/raw_repo_handoff_scored_v1/workflow.py` contains the inherited arm dispatcher.
* `analysis/raw_issue_feedback_entry_v2` contains the inherited capacity calculation and native context integration.
* `analysis/mini_swe_capped_v1` contains project configuration/runtime wrappers. They identify mini 2.4.6 and retained upstream templates; the upstream wheel and its full dependency closure are not bundled.
* `analysis/raw_repo_handoff_score_recovery_v1` contains the fixed grader adapter, grading rule and candidate-syntax proof implementations. These are source code, not private grader inputs, status logs, or test contents. The exception and its unreported application count are explained in `METHODS.md`.
* `score_equivalence_key.py.txt` and `capacity_score_seal_wrapper.py.txt` are verbatim source-line excerpts, not standalone modules. Exact source ranges and full-original-file hashes are in `PROVENANCE.json`.
* `policy.json` contains an explicit public field whitelist. Endpoint, credential mode, account/transport details and request contents are omitted. `naive_package_seal.json` retains final package and attempt-selection provenance.
* `export_metadata.py` is a newly written field-export utility, not historical experiment code. It requires explicitly supplied source/output paths, imports no project modules, and does not run models, containers, tests or scoring. It only creates the selected new release files. The original checkout is needed to rerun this export.

`PROVENANCE.json` records 35 byte-for-byte copies whose file hashes match original method/launch bindings, two verbatim excerpts bound to the original scoring plan, and the sources/transformations of all data projections. `extraction_checks.json` reports structural checks on the new export. These checks do not establish new research results.

The source files intentionally retain original import paths and historical stage names. Relocated source bytes are unchanged; dependencies outside this inspection closure may be absent. Do not use module import success as a claimed reproduction result.
