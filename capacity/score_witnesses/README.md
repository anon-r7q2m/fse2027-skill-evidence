# Existing capacity grading and first-stop witnesses

This release was assembled from existing frozen records. No solver, model,
scorer, tests, patch replay, or target experiment was executed during export.

`grading_witnesses.json` contains 108 representative scoring inputs and their
192 logical policy/repeat rows. All 108 reports used ORIGINAL_PORTABLE_RULES;
the candidate-syntax exception was applied zero times. The representative
classifications are 67 resolved and 41 unresolved. These are not 108 independent
tasks. The frozen primary task denominator remains 16. Report classification,
anonymous test-status counts, saved replay identities and stage outcomes are
separate fields. Install returned nonzero in 40 records under the recorded
nonfatal policy; test-command returned nonzero in 42. Return codes are not
benchmark rewards, and this export does not diagnose those install returns.

`lnpn_first_stop_witnesses.json` retains all 16 primary LnPn paths. Ten stopped
at the first local input estimate before a model request: 74,440–91,059 versus
65,536. One localized a nonempty available .pyx file and stopped at the pool
input-domain boundary. Five have no stop in the inspected fields; null does
not imply task success. Local estimates are not exact server-side token counts.
These are observations of installed policies, not isolated editor efficacy or
the measured benefit of an unexecuted repair.

Test names/source/expected outputs, candidate patch contents, logs, private
annotations, model prompts/responses/reasoning, account/transport fields, and
the stored commitment nonce are excluded. Only the non-Python domain witness
exports two selected production-file paths; other source selections are counts.
The public counts reproduce saved grading metrics, but do not independently
reexecute tests. Submitted patches and raw test logs are not included, so this
is not a complete 108-input scoring replay package.

`provenance.json` records original source byte hashes, transformation rules,
and new output hashes. New projections are not historical preregistrations or
independent proof of unaltered history. Original commitment digests retain their
own semantics; they are not relabeled file-byte digests. The verifier checked
four committed files per input using the original nonce in memory, read actual
selected patch bytes only to verify their identities, and checked the written
allowlisted output once. `verification_receipt.json` states these narrow checks.

The public score-cell links preserve the existing task/base/final-tree/grader
identity grouping. Shared rewards are not grouped merely because values match.
The release changes no frozen outcome, score, or experimental denominator.
