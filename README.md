# From Agents to Skills: anonymous review artifact

This artifact accompanies **From Agents to Skills: An Empirical Study of
Mechanism Reuse**. Agent2Skill is the human-guided, template-supported reuse
setting studied here. The paper separates source correspondence, finite package
qualification, actual host delivery and installed-policy task utility.

## Start with the reuse chains

- [Reuse evidence and publication scope](reuse/PUBLICATION.md), with the
  [detailed source/package/host guide](reuse/README.md): historical `P_sel`
  source-fallback omission, Aider's unchanged-package host correction and G's
  three-module state/effect boundary. P calibration seams, Aider's recorded
  factory/transport, G's invalid model source account and reported-only entry
  remain explicit. This is a static evidence release, not a new experiment or
  complete historical host reproduction.
- [Nine-class development catalog](study/development_context.md) and
  [dated class records](records/README.md): six pinned donor families with
  conditional interfaces, adaptations and uneven public evidence. These are
  not nine independent discoveries or a transfer-success denominator.
- [GP original decision witnesses](witnesses/gp/README.md): preservation
  evidence concerns a legally restored tree, while selection publishes the
  original candidate. The historical selector `P_sel` is distinct from the
  later SEARCH/REPLACE editor `P` in AP and LP.
- [Installed policies and measured outcomes](capacity/METHODS.md): all 192
  logical capacity rows, 108 unique grading inputs, primary sixteen-task panel,
  comparator policies, dependent repeats and realized usage. The
  [complete paired/repeat figure](study/capacity_figure/README.md) retains all
  comparisons. Neither score identities nor public CSV arithmetic rerun grading.

## Explanatory probes and analysis records

- [Four frozen native predictions](prospective/README.md): 42 observations on
  fourteen inputs with separate interventions and lawful controls. The
  [prior-art disclosure](study/prior_art_20260929.md) credits earlier public
  reports for a21 and s12. Native defects are not skill-extraction failures.
- [Full-team extension](native_integration/README.md): nine observations of
  a known mechanism through saved/reloaded configuration and actual artifact
  review. Scoped T/C support does not erase U's failed metadata assertion or
  the false global prerequisite.
- [Case-analysis worksheet](study/case_analysis/WORKSHEET.md) and
  [full Django worked record](study/case_analysis/DJANGO_FULL_RECORD.tex):
  facts, obligations, competing explanations and correction limits. The TeX
  record is an archived manuscript fragment, not a standalone document.
- [Fixed external-case use](transfer_use/README.md): eight original analyses
  on four curated decision units, including a secondary omission and unknown
  historical dimensions. No ordinary-review comparison or executed repair is
  established.
- [Audit guide](audit/README.md): measurement-contract research and aggregate
  triage, without private individual annotations or formal blacklist authority.

## What can be recomputed

The existing offline entries and their disclosed scopes are listed in the
[preserved earlier reading guide](study/README-focused-20260929.md).
The public parser and source-slice replays do not execute the historical full
host or official graders. `python3 -B capacity/summarize_outcomes.py` recomputes
existing released outcome counts and paired tests. The new `reuse/` directory
is for inspection and does not introduce a replay or self-contained runner.
Its `.py.txt` files are exact source excerpts, not runnable modules.

Start with [claim-level evidence](CLAIM_EVIDENCE.md) for coverage and evidence
levels. Public source bytes, selected code copies, metadata projections,
historical summaries and reported-only endpoints are deliberately distinct.
Independent assessment inputs, complete model traffic, submitted grading
patches, raw grade logs and private audit annotations remain excluded.
