## Public source counterexample before generation

An independent evaluator maintainer creates one new public event sequence from
the fixed donor and public ABI, with a minimum-failure empty-key reproduced
candidate, a minimum-failure nonempty nonreproduced candidate, and a
higher-failure nonempty candidate positioned before the correct choice to expose
the wrong fallback and first-appearance tie. The original donor determines the expected ranking. Run the original
L3 control and original Direct through the unchanged isolated public evaluator:
the control must pass and Direct must fail for this branch. Record the actual
workers and cleanup. An evaluation-uncertain result stops preparation.

This new case is explicitly a public, source-review-driven development case.
It does not come from an independent hidden answer. Keep the original ten
public cases byte-for-byte; the new public suite appends this one case and keeps
the same candidate identity, complete target and effect ABI. No new host effect,
normalization implementation or hand-written candidate repair is introduced.
