# Dated source and execution records

These copies add inspectable evidence for the catalog and six explanatory families.
They are reports, public contracts, public mapping/calibration receipts, and a
recorded-response handoff witness. They do not distribute sealed assessment
inputs or reproduce complete host executions. Their dates, old budget balances,
next-step descriptions and verdicts describe their original study versions.
The 16-task release in `../capacity/` supersedes earlier *pending* capacity text
for current outcome reporting; it does not rewrite that historical chronology.

Relative links to files absent from this release are provenance pointers to the
research repository, not claims that those files are bundled. Use
`../CLAIM_EVIDENCE.md` for exact bundled entry points and evidence level.
