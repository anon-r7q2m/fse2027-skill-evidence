## Question and measured domain

This block keeps the original generated coordinate and SEARCH/REPLACE
packages, ordinary host, prompt/parser, K=4, admission, normalization and vote
unchanged. Only the previously generated prompt/parser differ between the two
pools. Each of twelve tasks has three fresh independent paths: ordinary N with
at most seven requests, coordinate C with four, and SEARCH/REPLACE P with four.
All paths use gpt-5-mini/medium, per-request input/output caps 65,536/8,192,
300 seconds per request, and 1,500 seconds solving plus 300 seconds finalization
after setup. Equal ceilings do not imply equal actual costs or search protocols.

The selection order and 138 historical exposure exclusions were frozen before
new issue reading. The first twelve statically compatible tasks are ranks
115--125 and 127. Rank 126 was excluded before generation because the declared
two-file repair domain contains 126,057 bytes, beyond the 98,304-byte limit;
this does not establish that a narrower repair is impossible. Reading stopped
at the twelfth eligible task. Django supplies 6/12 tasks, pytest 2/12, and four
other repositories one each. Rank 121's original public issue contains repair
advice. All three paths share the same public issue, human requirement card,
human source locations, complete editable files and extra source excerpts.
The result therefore concerns this assisted input domain, not unassisted
repository repair or unseen-source discovery.

Only N, C_vote and S_vote are primary score endpoints. The original sixty
first/vote/final outputs are retained, but first/vote score differences are
**UNMEASURED** in this new block. A shared task/base/tree/scorer identity may
