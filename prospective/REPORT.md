# Prospective native-workflow study: closed result

Date: 2026-09-29. The finite study is closed. This does not close the broader
historical research objective or establish a general diagnostic theory.

Two frameworks were selected before implementation inspection or behavior:
smolagents `227ef5e49ddd82339295939072f0223249aa8d38` and AutoGen
`027ecf0a379bcc1d09956d46d12d44a3ad9cee14`. Four fresh diagnostic contexts
received ordinary review or additional principle guidance under the same
90-minute maximum opportunity. Each froze one prediction and one local patch.
All four records preceded native execution. Exact server-model version and
training/history non-exposure are not independently attested.

Fourteen frozen inputs comprise six triggers and eight legal controls. Each
family's union runs on original source and each separate intervention: 42
calls. Six original trigger observations and six own-intervention observations
match their frozen predictions. Six cross-intervention trigger observations
remain; each local patch is not required to repair the other's mechanism.
All 24 control calls retain their declared behavior. Correct output under
optimization does not imply the original checker ran. Termination does not
certify execution or task success. No wiring repair, target replacement,
semantic retuning, paid model call, benchmark scoring or Docker run occurred.

Both ordinary and guided contexts found different supported mechanisms in
both frameworks. This supplies new native-workflow knowledge without an
observed guidance advantage in finding counts. The small purposive study
cannot establish method superiority, equivalence, human benefit, prevalence,
live-model utility or complete/minimal repairs. Trigger counts, native calls,
and framework families are not interchangeable denominators.

Independent static qualification and final adjudication are in
`protocol/`. Four original prediction hashes match
the pre-execution seals. A later identity check independently verified that
the label-concealed qualification copies removed only top-level metadata;
all retained semantic fields match. That post-execution verification is
explicitly dated and is not represented as a new pre-execution seal.

`observed/` retains all original native observations, launch receipts and the
complete execution matrix. `run_matrix.py` is the driver; the frozen patches
are under `diagnostics/*/intervention.patch`. Both
original source trees still match all pinned files. A separate distribution
check replays the same 42 calls through the path-anonymized public bundle;
all compared native fields and selected import origins match. It reuses the
recorded dependency environment, does not validate a fresh pip installation,
and adds no independent experimental samples.
