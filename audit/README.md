# Public audit evidence

This folder retains four existing public reports/method files without editing their contents. The protocol describes the initial seven-benchmark contract audit; the population delivery concerns a subsequent six-benchmark branch and 4,989 heterogeneous audit units. Do not pool the two scopes.

The population report contains privacy-suppressed aggregates. Concerns are not invalid tasks; static repair proposals are not runtime-validated repairs. Formal task validity, blacklist publication, and a numeric Benchmark Validity Ceiling remain unresolved.

The Pro follow-up is source-level analysis of a pinned standalone evaluator. Its source URL, revision, hash, and line ranges permit inspection without access to private task judgments. The pinned evaluator hash was rechecked during this manuscript revision; no evaluator or benchmark job was executed. These findings do not establish the live leaderboard intake policy.

The original aggregate generator and disposition mergers depend on restricted review records. This small public candidate does not regenerate those individual judgments or the whole audit. No restricted task IDs, annotations, evaluator-only cases, or review partitions have been copied.
