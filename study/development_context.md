### G: Existing-test preservation checking

Donor: agentless. Target profile: `agent2skill.json-effects.g.trial-v1`.

- **Source preconditions:** An actual base-PASSED inventory and tests that can be related to the candidate snapshot.
- **Consumer:** Source regression selection/reranking; in the target, the next solver request and, in the historical GP block, the candidate selector.
- **Dependencies:** Native-log parsing, frozen preservation obligations, snapshot identity, isolated execution and original-test projection.
- **Host adaptation:** Offline regression evidence becomes in-loop checking and delivered feedback. Complete inventory, three-state obligations and native syntax are declared adaptations.
- **Observed boundary:** Historical GP projection erased test-only candidate differences. Complete preservation receipts did not assert issue repair. The model's source metadata was invalid; independent source review supplied traceability.
- **Qualification, counterexample or repair:** A model repaired only native_logs.py; inherited modules were unchanged. Public 31/31, reused regression 8/8 and the same-package recorded entry passed. A GP path with one candidate solved its task; selector increment was unmeasured.

Included public reports: [g_native_log_repair_v1](../records/results_cache/g_native_log_repair_v1/REPORT.md).

### R: Issue reproduction and post-change checking

Donor: agentless. Target profile: `r_full_package_v1 effect grammar; r_behavior_transfer_v1 complete-script contract; r_behavior_api_v1 prompt adaptation`.

- **Source preconditions:** An issue behavior that can be exercised through the required public operation chain; a generated script must meet base-admission conditions.
- **Consumer:** Source reproduction execution/reranking; target solver feedback and candidate checking in RP.
- **Dependencies:** Source context, generation prompts, script extraction, observable assertions, isolated execution, frozen scripts and snapshot-bound receipts.
- **Host adaptation:** Prepare, execute on base, admit, freeze and recheck. API operations, observed results and assertions are explicit target adaptations.
- **Observed boundary:** The current R/RP block admitted no reproducer in eight relevant paths. Some SIGKILL causes remain UNKNOWN. Older R versions and their scores are separate.
- **Qualification, counterexample or repair:** The current package passed public 8/8 and reused independent 22/22. A same-fixture generated checker accepted the complete repair and rejected two shallow repairs; this is exposed development evidence.

Included public reports: [r_behavior_api_v1](../records/results_cache/r_behavior_api_v1/REPORT.md).

### C: Context removal, duplicate bookkeeping and feedback

Donor: moatless. Target profile: `checking_context_hook_v1`.

- **Source preconditions:** Known FileContext members and ordered removal requests, including repeated keys.
- **Consumer:** Source CleanupContext Observation; target ModelView and the next solver request.
- **Dependencies:** Membership state, deletion bookkeeping and feedback; target observation identities, selection policy and pressure threshold.
- **Host adaptation:** File keys become eligible observation IDs. The package requests projection and the host delivers it. The selector and pressure policy are adaptations, not donor-provided generic compression.
- **Observed boundary:** All 30 recorded replacements were delivered, but there were zero input readmissions. Deleted content was sometimes read again; logs with an outer zero exit code could contain failures. No causal score loss is identified.
- **Qualification, counterexample or repair:** Both implementations passed public 9/9 and independent 6/6; the accepted unchanged package passed ordinary and one-request-left entries. Two implementations count as one class.

## Fixed capacity comparison

The [methods supplement](../capacity/METHODS.md) retains installed-policy definitions, original method/source bindings, selection and score identities. All eight arms used recorded gpt-5-mini/medium, at most nine requests per path, 65,536 input and 8,192 output tokens per request, and a 300-second request timeout. Solving allowed 1,500 seconds plus 300 seconds finalization. Localization/discovery could use at most five requests; four pool candidates at most one each. These are equal ceilings, not equal realized cost or an isolated synergy intervention.

N is the native loop; L/Ln add distinct fixed locators; P/Pn have distinct candidate formats and selectors; LP/LnPn combine their corresponding implemented policies. Hmini uses pinned mini-SWE-agent 2.4.6 under the common request ceiling. The pre-edit capacity decision preserves the clock and unused allowance; there is no post-failure pool rescue. P's newline-normalized representation bound and Pn's twice-original-UTF8 prospective proxy are different admission rules. Detailed algorithms, source copies and licensing remain in [METHODS.md](../capacity/METHODS.md); the host distribution is not import-complete.

The primary sample is sixteen task IDs, ranks 194–209 under the recorded selection. Its actual exclusion chain is retained, rather than approximated from the rank labels. Four IDs selected before outcomes have two extra repeats: **24 task-repeat blocks, 192 logical policy paths, 108 distinct score inputs, 84 shared mappings, zero missing outcomes**. Neither 192 paths nor 108 grades is a count of independent tasks. Score sharing is bound to task/base/tree/task-file/grader identity, not equal reward.
