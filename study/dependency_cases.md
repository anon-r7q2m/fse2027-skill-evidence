# Transfer and composition: retrospective case evidence

2026-09-28. This is a bounded synthesis of existing public reports and witnesses. It adds no model calls, donor execution, benchmark runs or new task scores. The companion [JSON matrix](FSE_DEPENDENCY_CASES_20260928.json) retains the six fields and version references in machine-readable form.

## Scope and units

The current catalog contains nine accepted classes from six donors: eight given-target L2 classes and one same-source-development L1 class. It is a survivor catalog, not an extraction denominator. Two older positive migration cohorts remain separate because their host profiles differ. Repairs and repeated checks are longitudinal observations, not additional mechanisms.

The discovery inventory below fixes its scope to four named discovery epochs, their single mapping continuation, and the explicitly listed earlier interface/transport histories. It retains no-candidate cells as well as named proposals. Static context-source screening is a separate evidence type. No rate of extraction failure, donor ranking, category prevalence or library-size fragility is estimated. Evidence that stops before source behavior, generated code or task execution does not receive a later-stage failure label.

The effect inventory covers the completed composition and complete-harness comparison blocks referenced by PROJECT_HANDOFF.md and MECHANISM_EVIDENCE_INDEX.md at this snapshot. Task, repeat, arm, solver prefix, candidate and benchmark score are different units. Each block keeps its own population, package versions, budget and trial reducer; rows are never pooled.

## Findings supported by the cases

1. A source boundary includes the producers and consumers needed for the behavior. The Moatless history selector consumes typed summaries; Trae LakeView annotations instead reach a UI. This does not prevent other mechanisms from either donor being transferred.
2. Source behavior and target reachability are separate. NexAU/AHE's original compactor supports four declared cases, but the frozen target mapping selects an empty ownership class. Its continuation repairs ownership but leaves configuration delivery unspecified.
3. The meaning and projection of evidence constrain composition. In the historical GP block, restoring tests maps two test-only candidates to the same checked tree. Preservation PASS cannot supply the missing syntax or issue-repair judgment.
4. These boundaries coexist with successful transfers and ordinary repairable defects. Aider and accepted Trae feedback reach their declared consumers; the issue-length implementation error and chooser staging fault have documented repairs. None establishes a universal impossibility result.

Benchmark-quality auditing remains a separate contribution on measurement contracts. Its six-benchmark report covers 4,989 heterogeneous static dispositions; formal validity, BVC and authoritative blacklist decisions remain unresolved. It does not remove tasks from any effect block here. See [analysis/benchmark_hard_audit_fse_v1/decision_oriented_delivery_2026-08-31.md](../analysis/benchmark_hard_audit_fse_v1/decision_oriented_delivery_2026-08-31.md).

## Deep case: GP evidence projection

The historical selector in GP is package 5f70bae4…6e93, not the accepted SEARCH/REPLACE editor. On django-13925, the earlier candidate adds a test with literal leading plus signs and produces a public SyntaxError; a later candidate removes them. Both only change tests. G restores the checked tests to base, leaving no candidate entries in either checked projection, so both receive 4/4 preservation PASS on the same base tree. RAW/Python keys remain distinct, with one vote each; first-occurrence tie-breaking selects the earlier original snapshot. These are recorded actions, not a newly executed counterfactual.

All five GP candidate receipts are complete and comparable, with zero preservation failures and unknown issue-fixed status. Six of eight P-bearing paths contain one candidate, and two have distinct one-vote candidates; checkpoints are not independent samples. The chosen earlier patch scores zero, but the later current patch has no official score and is also test-only. The evidence therefore identifies information loss in this decision, not a proven lost solve. On django-11292 the same composition submits its sole candidate and scores one; no selector increment is identifiable there.

The relevant design implication is to expose the scope of a receipt and which candidate changes survive projection. It is not to reinterpret preservation as an issue-correctness oracle or to weaken test restoration retrospectively. Evidence: [results_cache/gp_generated_effect_v1/DIAGNOSIS.md](../results_cache/gp_generated_effect_v1/DIAGNOSIS.md).

## Deep case: NexAU/AHE ownership and configuration

The AHE compactor and NexAU message types are pinned separately. Four original-entry cases support the card's O1/O2; the first missing-Pydantic import failed before donor entry and is not a donor-semantic failure. A witness with actual target classes establishes that host-owned observations can be projected while ownership remains host. The original card selects only package-owned observations, begins with none, and declares no creation effect. Its required eligible population is therefore unreachable at that entry.

The single continuation changes selection to eligible host observations, which repairs that restriction. It still omits how configurable keep_iterations reaches the initial empty state. The donor factory supplies configuration; hardcoding the constructor default would narrow the frozen obligation. Existing host configuration capability does not fill in an unspecified proposal. The card is rejected before code generation; no claim about generated compaction performance follows. ## Review and stopping rule

The catalog, discovery coverage and completed-effect inventory were cross-checked in separate read-only reviews against the linked public records. A final consistency check covers this matrix and the corresponding manuscript additions. This is artifact-assisted retrospective synthesis, not blinded coding with an inter-rater statistic. The bounded analysis stops after these checks; it does not allocate new extraction, scaling or benchmark experiments. Only the already launched original uniform scoring phase remains in progress.
