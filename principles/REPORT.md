# Bounded principles diagnostics: completed local evidence

2026-09-28. The fixed analysis and all **20 offline fixture conditions** are
complete: GP 6, feedback 8 and Pro evaluator 6. These are reused source objects
and synthetic controls, not 20 independent tasks. No model, benchmark,
container or official scoring call was added.

The result supports specific checks and a retrospective explanatory framework.
It does **not** establish additional prevention value for generic scope
metadata or a general theory of skill reuse. H1's factorial was cancelled
before execution because a distinct scope treatment could not be defined.
For H2, an equally small direct-helper control detects the same regression as
the caller-path control. These competing explanations are retained outcomes.

## What each principle can now claim

- **P1, intended use and extraction boundary:** retrospective source/profile
  evidence and a successful Aider adaptation; no new transfer execution or
  proof of dependency completeness/minimality.
- **P2, object and property with evidence:** concrete ranking and evaluator
  source replays, including legitimate limited uses. The GP change is a local
  syntax exclusion; scope metadata has no separately identified policy effect.
- **P3, producer path and explicit preservation obligation:** the original
  caller transformation identifies a missed control input. Directly testing
  that input is equally effective in this case. Old outputs alone are not the
  authority for preservation, and legal adaptations remain allowed.

All expected observations match, including deliberately failing checks and
abstention. This is replay agreement, not a pooled success or accuracy rate.
Normal-control counts have different units across the groups and are not added.

## Fix record and source boundaries

GP and Pro completed their first execution with no implementation correction.
Feedback used its one permitted fix: a reducer compared the helper's root-free
substring with a final SQL-path parameter. The fix compares the actual asserted
return value. Frozen inputs, assertions and expected outcomes did not change;
the initial runner and result remain in the feedback bundle.

The groups execute exact selected original functions/methods. Inputs such as
recorded selection keys, synthetic normalization keys, mock ORM construction
and deterministic worker outcomes enter only at disclosed boundaries. These
are not complete agent, donor, database or benchmark reproductions. Project
authored wrappers and policy interventions are separated from original source.

In-product coding agents drafted and cross-checked the protocol, case labels,
implementations and claim boundaries under the user's direction. Their agreement
is not independent human annotation. Source, executable observations and the
retained failure record support the claims.
